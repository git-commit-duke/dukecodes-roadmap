# 1. Record decisions as ADRs

Status: accepted
Date: 2026-10-24

## Context
Decisions with trade-offs get lost in chat and PR threads.

## Decision
Any choice with real trade-offs (tool, architecture, security control, exposed port) gets an ADR from `0000-template.md`.

## Pros
Reviewable history; interview-ready explanations of why.

## Cons
A few minutes per decision.
