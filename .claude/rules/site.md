# Showcase page
- `site/index.html` is generated by `roadmap build`. Never edit it by hand; CI fails when it's stale.
- Page text comes from the repo files and `showcase.toml`. Don't hard-code progress anywhere: it comes from ticks and the ledger.
- `site/assets/*` is synced verbatim from dukecodes-project-template. Change it there, then sync. Roadmap-only CSS goes in `site/src/roadmap.css` with an `rm-` prefix.
- The page runs under a hash-pinned CSP with Trusted Types. `roadmap.js` builds DOM nodes only: no innerHTML or other HTML-string sinks, no inline `style` attributes (use `el.style.setProperty`), no eval, no inline handlers.
- Links from data are https or `#token` only. Never publish real IPs, hostnames, MACs or tailnet names: `roadmap check` scans the built page too.
